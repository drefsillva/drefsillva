      alt="Animação da cobrinha percorrendo o gráfico de contribuições"

      width="100%"
    />
  </picture>

</div>

> **Configuração necessária:** a animação acima só aparecerá depois que o GitHub Actions gerar e publicar os arquivos SVG na branch `output`. Adicione o workflow abaixo em `.github/workflows/snake.yml` no repositório `drefsillva/drefsillva`.

<details>
  <summary><strong>Ver configuração do GitHub Actions para a cobrinha</strong></summary>

  Crie o arquivo `.github/workflows/snake.yml` com este conteúdo:

  ```yaml
  name: Generate Contribution Snake

  on:
    schedule:
      - cron: "0 0 * * *"
    workflow_dispatch:
    push:
      branches:
        - main

  permissions:
    contents: write

  jobs:
    generate:
      runs-on: ubuntu-latest
      timeout-minutes: 10

      steps:
        - name: Generate contribution snake
          uses: Platane/snk@v3
          with:
            github_user_name: ${{ github.repository_owner }}
            outputs: |
              dist/github-contribution-grid-snake.svg
              dist/github-contribution-grid-snake-dark.svg?palette=github-dark

        - name: Publish SVG files
          uses: crazy-max/ghaction-github-pages@v4
          with:
            target_branch: output
            build_dir: dist
          env:
            GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
